# Лабораторная работа №1

## Задание
Сделайте окно, кнопку и надпись, при нажатии кнопки надпись меняется на изображение

## Описание
Программа демонстрирует базовые возможности библиотеки **Tkinter** для создания графического интерфейса пользователя (GUI):

- создание главного окна;
- размещение виджетов (`Label`, `Button`);
- обработка события нажатия на кнопку;
- загрузка и отображение изображения с помощью библиотеки **Pillow** (`PIL`);
- сохранение пропорций изображения при уменьшении.

Изначально в окне отображается текстовая надпись **«Ниже волшебная кнопка»**. После нажатия на кнопку **«Нажми на меня!»** надпись заменяется на картинку `image.png`.

## Требования

- **Python** 3.8 или выше
- Библиотеки:
  - `tkinter` — входит в стандартную поставку Python (отдельно устанавливать не нужно)
  - `Pillow` — требуется установить
