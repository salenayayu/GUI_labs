# Лабораторная работа №2

## Задание
Сделать окно с полями ввода курс доллар - рубль - евро

## Описание
Можно вводить дробные числа с точкой или запятой. При пустом или неверном вводе
показывается подсказка; остальные поля сохраняют последние рассчитанные суммы.
Результаты округляются до двух знаков после запятой.

## Требования

- **Python** 3.8 или выше
- Библиотеки:
  - `tkinter` — входит в стандартную поставку Python (отдельно устанавливать не нужно)
